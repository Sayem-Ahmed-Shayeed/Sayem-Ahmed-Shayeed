01 / THE SHORT VERSION

I’m a builder who likes the intersection of clean interfaces, useful systems, and smart automation.

I care about the part users feel — speed, clarity, flow, and the tiny details that make software pleasant to use.

Right now I’m going deeper into Full Stack Web Development and Automation, while continuing to build with Python, Android, databases, and AI.

Current rule: if something is repetitive, I want to automate it. If something is confusing, I want to redesign it.
